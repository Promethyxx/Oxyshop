# Security Policy

## Supported Versions

Only the latest release is supported. Please update before reporting.

## Reporting a Vulnerability

Do not open a public issue. Send a private report through the "Security" tab of this repository ("Report a vulnerability").

Please include:
- Affected version and operating system
- Description of the vulnerability and its impact
- Steps to reproduce or a proof of concept
- Any suggested fix, if you have one

You will get a response within 7 days. Please allow time for a fix before any public disclosure.
